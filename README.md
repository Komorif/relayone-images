# Images Gallery

A responsive static photo gallery with local WebP assets, a keyboard-accessible lightbox, and Docker/Caddy configuration.

Per-server settings are defined in `.env.example`; local `.env` files and certificate data are excluded from Git. Only the gallery runs in Docker; VPN services are managed separately.

Photo sources and third-party image license information: [PHOTO-SOURCES.md](PHOTO-SOURCES.md).
